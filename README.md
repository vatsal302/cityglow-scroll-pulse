# Urbanmesh - Smart Urban Mobility

Urbanmesh is an interactive smart-mobility platform featuring a real-time WebGL city. It provides capabilities like live traffic telemetry, multi-modal routing, and public transit schedules in a single, beautiful operator's console.

## Features

- **Immersive 3D Interface**: Powered by Three.js and React Three Fiber for a real-time, responsive diorama city.
- **Scroll-driven Animations**: Seamless camera transitions and data visualizations controlled by the user's scroll position.
- **Live Traffic Visualization**: Dynamic flow lines and glowing incident markers representing urban density.
- **Multi-Modal Planner**: Fast route solver comparing transit modes with ETA and energy costs.
- **Responsive & Modern UI**: Built with React, Tailwind CSS, and Framer Motion for a sleek, glassmorphism aesthetic.

## Tech Stack

- **React** with Vite
- **TypeScript**
- **Three.js** / **React Three Fiber**
- **Tailwind CSS**
- **Lucide Icons**
- **TanStack Router**

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
